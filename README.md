This repository contains the source code for the Megane Hackathon website, a Jekyll-based site for an event focused on hacking glasses and eyewear technology.

The Megane Hackathon is an event where developers, designers, and creators come together to build anything related to glasses. Participants can create physical eyeglasses, develop apps and games for the latest smart glasses, and freely "hack" eyewear in new and exciting ways.

## About the Event

-   **Theme**: A hackathon for creating physical glasses, apps for smart glasses, or any other project related to eyewear.
-   **Location**: Koyo Hall in Sabae City, Fukui—the "mecca of eyeglasses" in Japan.
-   **Dates**:
    -   May 28, 2016 (Sat) 10:20 - 17:00
    -   May 29, 2016 (Sun) 10:20 - 16:00
-   **Registration**: Prior registration via [Connpass](http://codeforfukui.connpass.com/event/30182/) is recommended, but on-site registration is also accepted.

## Resources for Participants

A variety of hardware, data, and materials are available to support creative projects:

-   **Wearable Devices**:
    -   MOVERIO BT-200
    -   Vuzix M100
    -   Sony Eyeglass
-   **Prototyping Hardware**:
    -   The [IchigoJam](http://ichigojam.net) computer for simple programming.
    -   A [Switch Science Aid Station](https://www.switch-science.com/info/aidstation/) for on-site purchase of electronic components.
-   **3D Data for Custom Frames**:
    -   3D data for creating devices compatible with the "neo-plug" eyeglass frame. ([Read more](http://fukuno.jig.jp/1270))
-   **Open Data**:
    -   [Data City Sabae](http://data.city.sabae.lg.jp/)
    -   [Fukui Prefecture Open Data Library](http://www.pref.fukui.lg.jp/doc/toukei-jouhou/opendata/)
    -   [DATA.GO.JP](http://www.data.go.jp/)
    -   [Open Data Platform (SPARQL)](http://sparql.odp.jig.jp/)
-   **Creative Materials**:
    -   Papercraft and idea sheets to help brainstorm and prototype.

## Website Development

This site is built with Jekyll. To run it locally:

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    bundle install
    ```
3.  Serve the website locally:
    ```bash
    bundle exec jekyll serve
    ```
4.  Open your browser to `http://localhost:4000`.
